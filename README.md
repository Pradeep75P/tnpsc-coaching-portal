# 🏛️ TNPSC Vetri Pathai | குரூப் IV & வி.ஏ.ஓ பயிற்சி தளம்

A modern, high-performance coaching portal and online CBT/OMR mock examination platform for **TNPSC Group IV & VAO Aspirants**.

---

## 🚀 Instant Deployment to Vercel

### Method 1: Using Vercel CLI (Recommended)
Open your terminal in this directory (`tnpsc-coaching-portal`) and run:
```bash
npx vercel
```
- When prompted to login, authenticate via your browser (GitHub, GitLab, or Email).
- Press **Enter** to accept the default project settings.
- To deploy directly to production:
```bash
npx vercel --prod
```

### Method 2: Via GitHub & Vercel Dashboard
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial release of TNPSC Vetri Pathai Portal"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. Navigate to [Vercel Dashboard](https://vercel.com/new).
3. Import your repository and click **Deploy** (zero build configuration required).

## 🌟 Key Features

1. **Previous Year Question Papers (PYQ 2014 - 2024)**:
   - Official question papers with bilingual solutions (Tamil & English).
   - Real-time CBT Computer-Based Test Engine with timer, palette, and question status.
   - Authentic TNPSC OMR Sheet Simulation with pencil shading sounds and Part-IV verification audit.
   - Printable question papers with official answer keys.

2. **Daily Practice Question (இன்றைய வினா)**:
   - Live Question of the Day with instant evaluation, audio chimes, detailed explanations, and daily streak tracking.

3. **Cut-off & Post-Wise Selection Predictor**:
   - Community category calculation (GT, BC, BCM, MBC, SC, SCA, ST).
   - 20% PSTM (Tamil Medium) and 30% Women horizontal reservation adjustments.
   - Typist & Steno-Typist certificate eligibility bonuses.
   - Real-time probability meters for VAO, Junior Assistant, Bill Collector, and Field Surveyor posts.

4. **Samacheer Kalvi Study Notes Reader Modal**:
   - Interactive reading viewer with high-yield revision summaries, mnemonics, tables, and printable revision sheets.

5. **Accessibility & Aesthetics**:
   - Dark Mode / Light Mode toggle with persistence.
   - Bilingual Tamil / English interface switch.
   - Full keyboard shortcuts (`1-5`, `A-E`, `Arrow keys`, `M`, `C`).
